# AI 사서 보조 싱글 에이전트

컴퓨터공학부 202158070 이인재

project_4/05_full_agent.py의 CS Mail Agent 구조를 도서관 업무에 적용한 중간과제입니다.
도서 11권은 과제 조건의 목록이며 대출 내역과 이용 규칙은 실습용 모의 데이터입니다.

## 실행

Python 3.12와 실행 중인 Ollama가 필요합니다. 다음 명령을 이 폴더에서 실행합니다.

```sh
python3 -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
ollama pull qwen3:4b-instruct-2507-q4_K_M
python 05_library_agent.py
```

Ollama가 실행 중이 아니면 Ollama 앱을 실행하거나 별도 터미널에서 `ollama serve`를 실행합니다.
현재 모델 이름을 다른 모델로 바꾸지 않습니다. 인터넷은 패키지와 모델을 준비할 때만 필요합니다.

프롬프트에 질문을 입력합니다. `/new`는 새 대화, `/quit`는 종료입니다.
같은 대화의 후속 질문은 단기 기억을 사용합니다. `/new` 이후에도 저장한 독서 선호는
같은 프로세스의 Store에서 유지되며, 프로그램을 종료하면 모든 기억이 사라집니다.
수업 자료와 같은 InMemoryStore 구현이며 디스크 영속 저장을 의미하지 않습니다.

예시 질문:

- 달빛 도서관의 비밀을 찾아줘.
- 방금 찾은 그 책의 저자 이름으로 다시 검색해줘.
- 내 대출 내역과 반납일을 알려줘. 모의 데이터라는 점도 명시해줘.
- 친구의 대출 내역을 알려줘.
- 나는 고양이 관련 책을 좋아해. 이 독서 선호를 저장해줘.
- `/new` 입력 후: 내가 저장한 독서 선호를 조회해줘.

## 기능

- 제목/저자 부분 검색, 검색 결과 없음 안내
- 현재 실습 이용자의 대출 조회와 이용 규칙 확인
- 회신 초안 도구 및 최종 출력 검수
- 사서 이름/역할 Runtime Context 주입
- 입력 정책과 의미 분류, 출력 Judge
- 동일 thread 대화 유지, 이용자별 namespace의 선호 저장

`reply_to_user`는 화면에 표시할 초안만 생성합니다. 이메일·문자 전송 기능이 아닙니다.
도구가 없는 대출 신청·예약·연장·운영 시간·서가 위치는 수행하거나 추측하지 않습니다.
일반적인 운영/검색 안내와 달리 실습 본인 대출은 고정된 `demo_user` 계정 데이터입니다.
실제 인증을 구현한 서비스가 아니므로 실사용자 개인정보를 입력하지 않습니다.

## 검증

```sh
python verify_agent.py
```

지정 모델을 실제 호출하므로 실행에 시간이 걸립니다. 실행하면 `validation_results.json`이
갱신됩니다. 저장된 결과는 특정 환경에서 한 번 수행한 기능 검증이며 일반적인 정확도나
개인정보 보호의 완전성을 입증하는 수치는 아닙니다. 의미 분류와 Judge는 같은 모델을 사용하므로
함께 오판할 수 있습니다. Context 창이 길어지면 오래된 대화가 충분히 반영되지 않을 수 있습니다.

`COURSE_MAPPING.md`에서 수업 코드와 대응 관계를 확인할 수 있습니다.
`requirements-lock.txt`는 검증 환경의 전체 패키지 버전 기록입니다.
